1. EXECUTIVE SUMMARY & PROJECT SCOPE
================================================================================
SHGConnect is a lightweight, mobile-responsive, offline-first Progressive Web 
App designed specifically for Self-Help Groups (SHGs) across India. It digitizes 
physical meeting registers, attendance tracking, monthly pool savings, loan 
disbursals, EMI repayments, and NABARD bank linkage audits without requiring 
Web3, Ethereum, MetaMask, or gas fees.

The system replaces manual register books with a cryptographically verifiable, 
append-only SHA-256 hash-chain ledger that runs entirely inside the user's web 
browser offline.

4. 2-OF-3 MULTI-SIGNATORY QUORUM & SMS RECEIPTS SPECIFICATIONS
================================================================================
--------------------------------------------------------------------------------
2-OF-3 MULTI-SIGNATORY PIN QUORUM CONSENSUS
--------------------------------------------------------------------------------
- Default Officers:
  * President (अध्यक्ष) : Default PIN "1111"
  * Secretary (सचिव) : Default PIN "2222"
  * Treasurer (खजिनदार): Default PIN "3333"
- PIN Verification: Hashes entered PIN with calculateSHA256 and compares against 
  stored SHA-256 hash.
- Quorum Gate: Step 4 of MeetingWizard requires at least 2 valid officer PIN 
  signatures before enabling the "Save Session to Ledger" commit button.
- Cryptographic Payload Injection:
  Payload = ${baseMeetingData}:SIGNERS=[${signer1.role},${signer2.role}]:SALT=${signatureProof}

--------------------------------------------------------------------------------
OUT-OF-BAND OFFLINE SMS AUDIT RECEIPTS
--------------------------------------------------------------------------------
- Broadcast Drawer: Triggers after successful block commit in Step 4.
- Generates Devanagari audit receipt strings:
  "माहिती: [गटनाव] बैठकीत आपली ₹[रक्कम] बचत जमा झाली. हजेरी: हजर. शिल्लक कर्ज: ₹[कर्ज]. ब्लॉक: #[Index]."
- Out-of-band delivery via `navigator.share` (Web Share API) or `sms:?body=...` URI.
