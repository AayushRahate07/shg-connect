# एसएचजी-कनेक्ट (SHGConnect)
### ग्रामीण महिला बचत गटांसाठी स्थानिक व डिजिटल वही ऑपरेटिंग सिस्टीम

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![PWA](https://img.shields.io/badge/PWA-Offline_First-emerald)](https://shg-connect-in.vercel.app/)

**एसएचजी-कनेक्ट (SHGConnect)** हे भारतातील ग्रामीण महिला स्वयंसहाय्यता बचत गटांसाठी (SHG) बनवलेले संपूर्ण डिजिटल आणि ऑफलाइन चालणारे ॲप आहे. गावातील बैठकीत इंटरनेट नसले तरीही हे ॲप प्रत्येक सदस्याची बचत, कर्ज परतफेड, रोख पेटी ताळमेळ आणि ठराव सुरक्षितपणे नोंदवते.

---

## 🌟 मुख्य वैशिष्ट्ये

1. **१००% ऑफलाइन काम (Offline-First):**
   - इंटरनेट नसतानाही बचत नोंद, कर्ज मंजुरी, आणि हप्ता परतफेड सुरळीत होते.
   - इंटरनेट सुरू झाल्यावर आपोआप क्लाउडवर सुरक्षित सिंक होते.

2. **हँडशेक ओटीपी पडताळणी (Handshake OTP):**
   - प्रमुखांनी रक्कम नोंदवल्यावर सभासदाच्या फोनवर तात्काळ ४-अंकी कोड येतो.
   - प्रत्यक्ष रोख पैसे दिल्याशिवाय आणि कोड पडताळल्याशिवाय रक्कम पेटीत जमा होत नाही.
   - स्मार्टफोन नसलेल्या सदस्यांसाठी **कागदी पावती (Paper Slip)** मोड उपलब्ध.

3. **गोपनीयता व सुरक्षा (👁 रक्कम लपवा):**
   - बैठकीत एकाच फोनवर अनेक महिला माहिती पाहत असताना 'रक्कम लपवा' बटनाने शिल्लक गुप्त (`₹ ••••`) ठेवता येते.
   - अनधिकृत बाहेर पडणे टाळण्यासाठी लॉगआउट खात्री व ॲप पिन लॉक.

4. **सोपी ग्रामीण मराठी व ध्वनी वाचन (🔊 ऐका):**
   - क्लिष्ट इंग्रजी संज्ञा काढून शुद्ध बोलचाल मराठी (मुद्दल, मासिक हप्ता, वही, काही नाही, हिशोब जुळला ✔).
   - डोळ्यांना ताण पडू नये म्हणून मोठा फॉन्ट आणि स्क्रीनवरील सर्व माहिती मराठीत वाचून दाखवणारे ध्वनी बटण.

5. **नाबार्ड पंचसूत्र मूल्यांकन (NABARD 0-100 Score):**
   - १. नियमित बैठक, २. नियमित बचत, ३. अंतर्गत कर्ज वाटप, ४. नियमित कर्ज परतफेड, ५. अद्ययावत हिशोब वही.
   - बँकेकडून थेट सीसीएल (CCL) कर्ज मिळवण्यासाठी स्वयंचलित आरोग्य वर्गवारी (A/B/C).

## 👥 ४-स्तरीय भूमिका व वापरकर्ते

| स्तर | भूमिका | अधिकार व कार्य |
|---|---|---|
| **स्तर १** | **सभासद (Member)** | स्वतःची जमा बचत, कर्ज बाकी, डिजिटल पासबुक, थेट बैठकीत हजेरी व हँडशेक कोड. |
| **स्तर २** | **गट प्रमुख (SHG Lead)** | थेट बैठक संचालन, रोख पेटी नोट मोजणी, बचत संकलन, कर्ज वाटप, कोरम पडताळणी. |
| **स्तर ३** | **अधिकारी (Animator/VO)** | कार्यक्षेत्रातील १० ते २० बचत गटांचे व्यवस्थापन, नवीन सदस्य मंजुरी, क्लस्टर आढावा. |
| **स्तर ४** | **लेखापरीक्षक (Auditor/Govt)** | जिल्हा व राज्यस्तरीय तपासणी, ब्लॉकचेन/क्रिप्टो लेजर पडताळणी, ताळेबंद अहवाल. |

## 📱 मोबाईल स्क्रीनवर कसे ठेवावे? (PWA Install)

1. तुमच्या मोबाईलच्या **Google Chrome** ब्राऊझरमध्ये लिंक उघडा.
2. खाली दिसणाऱ्या **"स्क्रीनवर ठेवा"** बटनावर टॅप करा.
3. किंवा ब्राऊझरच्या मेन्यूमधील (⋮) **"Add to Home Screen"** निवडा.
4. आता इंटरनेट बंद असले तरी ॲप थेट फोनमधील इतर ॲप्ससारखे वेगवान चालेल.

## 💻 संगणकावर सुरू कसे करावे? (Developer Setup)

```bash
# १. रिपॉझिटरी क्लोन करा
git clone https://github.com/AayushRahate07/shg-connect.git
cd shg-connect

# २. ॲप फोल्डरमध्ये जाऊन पॅकेज इन्स्टॉल करा
cd shgconnect-pwa
npm install

# ३. लोकल डेव्हलपमेंट सर्व्हर सुरू करा
npm run dev
```
