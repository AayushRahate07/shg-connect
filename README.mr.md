# एसएचजी-कनेक्ट (SHGConnect)
### ग्रामीण महिला बचत गटांसाठी स्थानिक व डिजिटल वही ऑपरेटिंग सिस्टीम

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![PWA](https://img.shields.io/badge/PWA-Offline_First-emerald)](https://shg-connect-in.vercel.app/)

**एसएचजी-कनेक्ट (SHGConnect)** हे भारतातील ग्रामीण महिला स्वयंसहाय्यता बचत गटांसाठी (SHG) बनवलेले संपूर्ण डिजिटल आणि ऑफलाइन चालणारे ॲप आहे. गावातील बैठकीत इंटरनेट नसले तरीही हे ॲप प्रत्येक सदस्याची बचत, कर्ज परतफेड, रोख पेटी ताळमेळ आणि ठराव सुरक्षितपणे नोंदवते.

---

## 🌟 मुख्य वैशिष्ट्ये

1. **१००% ऑफलाइन काम (Offline-First):**
   - इंटरनेट नसतानाही बचत नोंद, कर्ज मंजुरी, आणि हप्ता परतफेड सुरळीत होते.
   - इंटरनेट सुरू झाल्यावर आपोआप क्लाउडवर सुरक्षित सिंक होते.

2. **हँडशेक ओटीपी पडताळणी (Handshake OTP):**
   - प्रमुखांनी रक्कम नोंदवल्यावर सभासदाच्या फोनवर तात्काळ ४-अंकी कोड येतो.
   - प्रत्यक्ष रोख पैसे दिल्याशिवाय आणि कोड पडताळल्याशिवाय रक्कम पेटीत जमा होत नाही.

3. **गोपनीयता व सुरक्षा (👁 रक्कम लपवा):**
   - बैठकीत एकाच फोनवर अनेक महिला माहिती पाहत असताना 'रक्कम लपवा' बटनाने शिल्लक गुप्त (`₹ ••••`) ठेवता येते.
   - अनधिकृत बाहेर पडणे टाळण्यासाठी लॉगआउट खात्री व ॲप पिन लॉक.

4. **सोपी ग्रामीण मराठी व ध्वनी वाचन (🔊 ऐका):**
   - क्लिष्ट इंग्रजी संज्ञा काढून शुद्ध बोलचाल मराठी (मुद्दल, मासिक हप्ता, वही, काही नाही, हिशोब जुळला ✔).
   - डोळ्यांना ताण पडू नये म्हणून मोठा फॉन्ट आणि स्क्रीनवरील सर्व माहिती मराठीत वाचून दाखवणारे ध्वनी बटण.

5. **नाबार्ड पंचसूत्र मूल्यांकन (NABARD 0-100 Score):**
   - १. नियमित बैठक, २. नियमित बचत, ३. अंतर्गत कर्ज वाटप, ४. नियमित कर्ज परतफेड, ५. अद्ययावत हिशोब वही.
   - बँकेकडून थेट सीसीएल (CCL) कर्ज मिळवण्यासाठी स्वयंचलित आरोग्य वर्गवारी (A/B/C).

## 🔄 बैठकीचे दोन कार्यपद्धती मोड (Meeting Modes)

### मोड १: थेट मल्टी-फोन बैठक (Live Multi-Device Meeting)
- प्रमुखांच्या फोनवर ४-अंकी कक्ष कोड (`Room Code`) तयार होतो.
- सर्व सभासद आपापल्या फोनवरून थेट बैठकीत हजर होतात.
- सर्व उपस्थितांची यादी, ऑनलाइन स्थिती व बचत पडताळणी रिअल-टाइम स्क्रीनवर दिसते.
- बैठक पूर्ण होताच सर्व मंजूर बचत तात्काळ अधिकृत पासबुक व लेजरमध्ये जमा होते.

### मोड २: ऑफलाइन बैठक विझार्ड (Single-Device 4-Step Conductor)
- फक्त प्रमुखांकडेच फोन असल्यास वापरण्यासाठी २-ओळी × २-कॉलमचा सुटसुटीत विझार्ड:
  1. **१. उपस्थिती नोंद:** १-क्लिक हजेरी, रिसेट व प्रमाणिक खूण (Tick mark).
  2. **२. बचत व रोख संकलन:** प्रत्येक सदस्याची बचत नोंद.
  3. **३. ठराव व कर्ज वाटप:** बैठकीतील निर्णय व कर्ज वाटप.
  4. **४. कोरम व स्वाक्षरी:** किमान २ पदाधिकाऱ्यांच्या ४-अंकी सुरक्षित पिनद्वारे अंतिम स्वाक्षरी.

## 🚪 बैठकीतून लवकर बाहेर पडणे व तांत्रिक अडचणींचे निवारण (Edge Cases)

ग्रामीण भागातील बैठकांमध्ये बालक रडणे, जनावरांची काळजी, किंवा बॅटरी संपणे यांसारखी अपरिहार्य कारणे उद्भवतात. ॲपमध्ये यासाठी खास नियम आहेत:

### ३ अधिकृत उपस्थिती व बचत स्थिती (3 Departure States)

| स्थिती | प्रसंग | उपस्थिती कोरम | बचत व रोख नोंद | स्क्रीनवर दिसणारे स्वरूप |
| :--- | :--- | :--- | :--- | :--- |
| **स्थिती अ (State A)** | **पूर्ण बैठक उपस्थित** | हजर ग्राह्य | पूर्ण मंजूर रक्कम जमा | हिरवी टिक, ऑनलाइन बॅज |
| **स्थिती ब (State B)** | **बचत देऊन लवकर बाहेर पडली** | हजर ग्राह्य | पडताळलेली बचत सुरक्षित जमा | `[लवकर गेली • ₹X पडताळले]` |
| **स्थिती क (State C)** | **बिनबचत लवकर बाहेर पडली** | **हजर ग्राह्य (कोरम टिकतो)** | **काही नाही (कडक ₹० नोंद)** | `[लवकर बाहेर पडली]` + `[बिनबचत (₹०)]` |

### महत्त्वाचे नियम व सुरक्षितता:
1. **शून्य काल्पनिक रक्कम (No Phantom Money):** ॲप कधीही न भरलेली रक्कम मनाने (उदा. ₹२५० किंवा ₹३००) जोडत नाही. जर सदस्याने पैसे दिले नसतील, तर स्पष्ट ₹० राहते.
2. **सर्व मंजूर करा (Batch Confirm) चे कडक बंधन:**
   - हे बटण **केवळ तेव्हाच चालू होते जेव्हा एखादा हजर सदस्य अचानक नेटवर्क तुटल्यामुळे डिस्कनेक्ट होतो**.
   - लवकर बाहेर पडलेल्या सदस्यांवर (Left Early) याचा कोणताही परिणाम होत नाही.
   - प्रमुखांनी प्रत्यक्ष मिळालेली रक्कम टाकल्याशिवाय हे बटण पैसे जमा करू देत नाही.
3. **टॅब बंद किंवा मागे जाणे (Browser Back/Tab Close):**
   - सदस्याने चुकून टॅब बंद केल्यास किंवा फोन लॉक झाल्यास आपोआप सुरक्षित संकेत पाठवला जातो.
   - चालू असलेला ओटीपी कोड तात्काळ रद्द होतो आणि खोटी रक्कम जमा होत नाही.

## 👥 ४-स्तरीय भूमिका व वापरकर्ते

| स्तर | भूमिका | अधिकार व कार्य |
|---|---|---|
| **स्तर १** | **सभासद (Member)** | स्वतःची जमा बचत, कर्ज बाकी, डिजिटल पासबुक, थेट बैठकीत हजेरी, कारण निवडून बाहेर पडणे व हँडशेक कोड. |
| **स्तर २** | **गट प्रमुख (SHG Lead)** | थेट बैठक संचालन, रोख पेटी नोट मोजणी, बचत संकलन, कर्ज वाटप, कोरम पडताळणी. |
| **स्तर ३** | **अधिकारी (Animator/VO)** | कार्यक्षेत्रातील १० ते २० बचत गटांचे व्यवस्थापन, नवीन सदस्य मंजुरी, क्लस्टर आढावा. |
| **स्तर ४** | **लेखापरीक्षक (Auditor/Govt)** | जिल्हा व राज्यस्तरीय तपासणी, ब्लॉकचेन/क्रिप्टो लेजर पडताळणी, ताळेबंद अहवाल. |

## 📱 मोबाईल स्क्रीनवर कसे ठेवावे? (PWA Install)

1. तुमच्या मोबाईलच्या **Google Chrome** ब्राऊझरमध्ये लिंक उघडा.
2. खाली दिसणाऱ्या **"स्क्रीनवर ठेवा"** बटनावर टॅप करा.
3. किंवा ब्राऊझरच्या मेन्यूमधील (⋮) **"Add to Home Screen"** निवडा.
4. आता इंटरनेट बंद असले तरी ॲप थेट फोनमधील इतर ॲप्ससारखे वेगवान चालेल.

## 💻 संगणकावर सुरू कसे करावे? (Developer Setup)

```bash
# १. रिपॉझिटरी क्लोन करा
git clone https://github.com/AayushRahate07/shg-connect.git
cd shgconnect/shgconnect-pwa

# २. पॅकेज इन्स्टॉल करा
npm install

# ३. प्रोडक्शन बिल्ड तपासा
npm run build

# ४. सर्व नेटवर्कसाठी लोकल डेव्हलपमेंट सर्व्हर सुरू करा
npm run dev -- --host 0.0.0.0 --port 3000
```
